## Objective
- Builds a tcp client in C using standard lib functions
- Shows the full connect, send, rcv cycle
## Status
Completed

## Files
- **/Tutorial/** : This file contains some tutorials on socket programming in C
- **/src/v1.c** : This file contains the code for the client which connects to a remote server and receives something
- **/src/tcp_client.cpp** : This file contains code to create a tcp client who connects to a server on a hardcoded port. then sends and receives data
- **/src/tcp_server.cpp** : This file contains code to create a tcp server who accepts client and receives and send data
- **/src/Makefile** : This files contains the make commands to compile the tcp_server and tcp_client
